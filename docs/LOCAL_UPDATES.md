# 灰誓 macOS 本地更新

先安装 0.2.3。游戏「设置」中的「打开本地更新目录」会在访达中打开当前用户的补丁目录。
收到更新时，先把补丁的 `.pck` 文件复制进去，再放入 `update.json`，然后退出并重新打开游戏。
标题页会显示已加载的补丁编号。缺少补丁时，游戏会正常使用安装包自带的内容。

要退回安装包版本，把 `updates/update.json` 移出更新目录后重启。
如果暂时打不开游戏，也可在终端执行以下命令跳过本次更新加载。

```sh
open -n "/Applications/灰誓.app" --args -- --no-local-update
```

游戏数据与补丁放在不同文件。保留现有的 `save.json` 和备份即可继续原来的旅程。

## 版本基线

0.2.3 是新的安装包基线。应用会校验补丁清单里的 `base_version` 和底包 `灰誓.pck` 的 SHA-256，因此为 0.2.2 制作的补丁（编号 1–7）**不适用于 0.2.3**，会按设计被拒绝。如需继续分发补丁，必须相对 0.2.3 的原始 App 重新制作并从编号 1 开始计数。

签名的本地更新机制只适用于 macOS 安装包：启动引导在非 macOS 平台上直接返回基础包状态。Windows 版本不加载本地补丁，需要更新内容时请替换整个发布包。

## 制作补丁

保留交付时的原始 0.2.3 App。每次都相对同一份原始 App 生成补丁，并递增补丁编号。

```sh
python3 scripts/package_local_update.py \
  --base-app "交付/灰誓-0.2.3/macOS/灰誓.app" \
  --revision 1 \
  --output-dir "build/本地补丁-1"
```

打包工具使用项目固定的 Godot 4.7.2。它先写入带哈希文件名的 PCK，再一次性替换清单。应用会在加载游戏前检查签名、底包指纹和补丁内容。补丁只适用于对应的原始 App。同一版本号的其他构建也需要自己的补丁。

签名私钥默认保存在当前用户的 `Library/Application Support/灰誓发行`，只用于制作补丁。请将私钥留在仓库和交付目录之外。应用和项目只需要公钥 `data/update_public.pem`。

本地补丁可更新兼容的游戏脚本、关卡数据、场景及素材。制作补丁时保留内容数据版本与旧存档引用的卡牌、道具等 ID。涉及引擎、启动器、更新公钥或存档格式的变更时，发新版安装包并单独验证迁移。
